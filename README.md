app-clima-js

Descripcio:

Esta aplicacion aydua a busca de manera mas eficiente y rapida el estado de clima de cual quier lugar del mundo 

tecnologias:
APIs
DOM
LocalStorage

uso:

Al entrar a al navegador en para ver visualmente la aplicacion en el buscador se puede escribir el nombre de cual quier ciudad 
del mundo (la aplicacion lo logra realizar por la APIs ya que esta inteligencia es como el buscador que se utiliza para las consultas
en las aplicaciones). En la parte de abajo del buscador aparecera la temperatura, y como estan los pronosticos de humdad y lluvia
